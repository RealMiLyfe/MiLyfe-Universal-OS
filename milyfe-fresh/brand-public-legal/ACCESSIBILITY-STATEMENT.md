# Accessibility Statement — Phase 8

**Status:** `READY_FOR_REVIEW`. Accessibility is a baseline requirement (Roots), not a feature.

- Baseline: keyboard + screen-reader paths, contrast, reduced-motion, 44px touch targets, 6th-grade plain language, 10+ languages, audio-first modes, human support fallback.
- Every flow (join, vote, pay, dispute, learn, export, leave) must pass the access matrix before release; access modes built in (large text, high contrast, dyslexia-friendly, audio, low-bandwidth, offline-first).
- Feedback: "this screen fails a grandmother reading it aloud" is a blocking bug report with a human response path.
- Test evidence: Phase 11 (not fabricated here).
