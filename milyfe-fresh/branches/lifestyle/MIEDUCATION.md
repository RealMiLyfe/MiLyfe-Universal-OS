# MiEducation — Lifestyle Branch (Phase 5)

**Status:** `READY_FOR_REVIEW`. **Plain value:** learn anything, free, offline, at your pace — and leave with credentials that are really yours.
**Sources:** Lifestyle design §5 · Manual Learn tab (path WELCOME→FIND YOUR FEET→A CRAFT→A ROLE→TEACH; ten v1 paths), Bea helper, open badges, offline packs, teach mode.

- **Purpose:** learning paths, skills, courses, mentorship, credentials, training, lifelong development — always free, always offline-capable, never paywalled.
- **Users:** learners (kids via grown-up, adults, reentering, elders), teachers/mentors, tutors, credential issuers, employers (verification only).
- **Owns:** learning paths (10 v1: rights+papers, parenting, reentry, peace, food+first-aid, repair, honest money, literacy/languages, the-lacking-trade, run-a-street); journey landscape (visual progress); interactive exercises; offline packs; class hosting/publishing; teach mode (create + run classes); mentorship matching; open badges + credentials (issuer-signed, portable, leave-with-you); kid mode (play, safety, literacy — no money, no public story without grown-up).
- **Does not own:** universal reputation scores; credential claims without issuer authority; employment decisions; youth safety policy (MiChildGate).
- **Entities + data:** `paths` (steps, branches) · `enrollments` · `progress` (milestones as landmarks) · `classes` · `mentorships` · `credentials` (badge, issuer, evidence, revocation). Progress is the learner's; teachers see only their class slices.
- **Permissions:** enroll open; teach/publish needs path-owner or place approval; credential issuance needs issuer authority; youth progress visible to grown-up + chosen teachers only.
- **Contracts:** `edu.enroll/progress/publish/teach/mentor/issue/verify` + handoffs to work (credential→opportunity), place (street tutors), care (supported learning), gov (appeal of credential decisions).
- **Receipts:** enrollments, milestone completions, class publications, mentorship matches, credential issuance/verifications.
- **Offline:** offline packs (full paths + exercises); progress saves on-device; syncs later; classes hostable from cached packs.
- **Security:** credential forgery resistance (issuer signatures + revocation lists); no credential sale (buying-a-right forbidden); youth surfaces kid-safe-only.
- **Accessibility:** non-linear branching; multi-language; audio-first lessons; low-bandwidth packs; human tutors (street tutors, hello-day help).
- **Support:** learner help desk; "I'm stuck" tutor match; teacher support; credential dispute path (appeal, never silent revoke).
- **Legal:** credential honesty (issuer authority verified); youth education privacy; no fake accreditation claims.
- **Metrics:** enrollment/completion, offline-pack usage, teach-mode classes, mentorship outcomes, credential issuance/verification, learner growth.
- **Failure recovery:** lost progress → device + twin restore; bad credential → revoke + reissue + receipt; class failure → re-teach + remedy.
- **Export:** full learning record + credentials portable (open badges leave with you), even during dispute.
- **Removal:** unenroll with progress archive; credentials revoked only via due process + receipt; classes sunset with learner notice.
- **Fork behavior:** paths fork with lineage + issuer lineage; credentials stay verifiable across forks via issuer signatures.
- **Activation gate:** synthetic learners (kid, adult, reentering) run enroll→offline-pack→milestone→teach→credential→export; gates 1,2,4,6,7,8 pass.
