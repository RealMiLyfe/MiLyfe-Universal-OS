## Escalation ladders (tested in code, staffed by humans)

1. **Care:** support ticket → re-match/respite cover → safety escalation → human review → MiResolve/MiJustice.
2. **Health:** "who saw my data?" inspector + instant revoke → navigator → complaint to MiResolve.
3. **Place:** keeper → correction flow → project coaching → gov review (treasury freeze).
4. **Education:** tutor match → teacher support → credential dispute (appeal, never silent).
5. **Market:** merchant/buyer desks (7-day answer or standing note) → dispute → MiResolve → ledger correction.
6. **Work:** worker desk + "I wasn't paid" fast path (verify → claim → resolve) → labor-clinic routing.
7. **Governance:** facilitators → recount → pause (human-only) → fork right.
8. **Safety:** leave-now/panic → quarantine → human safety lead → real authorities where required.

## Response promises (proposed, TODO-human to adopt)

- Safety/emergency: immediate triage, human same day.
- Money-not-arrived / unpaid-work: fast path opened same day.
- Merchant complaints: answered ≤7 days or a public "doesn't answer" note (enforced in code).
- General help: answered ≤2 days during pilot.
