## Identity and growth

Read [`architecture/IDENTITY-ROOT-AND-SEED-TO-TREE-DESIGN.md`](architecture/IDENTITY-ROOT-AND-SEED-TO-TREE-DESIGN.md) for the final placement of identity services and the seed-to-tree growth model. Identity is a root principle and trunk service, not a branch-owned feature.

## Design rule

This package intentionally narrows the next design session. It does not expand the OS catalog, start implementation, or redesign the tree until the roots, trunk, three branches, four primary OSes per branch, and cross-branch contracts are accepted.

## Source integrity

- No original files were moved or deleted.
- This is a separated copy for focused design work.
- Changes made in this package must be reconciled back to the main workspace through an explicit review and decision.
- The package is not yet the GitHub repository.
